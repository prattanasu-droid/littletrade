# รายงานทดสอบมือถือ — Little Trade

วันที่ 9 พฤศจิกายน 2026

## ขอบเขต

เป็นการทดสอบอัตโนมัติแบบจำลองด้วย Node.js, React DOM/JSDOM และ Phaser 3 HEADLESS ใช้โค้ดฉากจริง ไม่ใช่การทดสอบบนโทรศัพท์หรือผ่าน Safari/Chrome และไม่มีภาพหน้าจอจากเบราว์เซอร์

- ตรวจกรอบผังที่แชร์กับ CSS ว่าอยู่ในจอและคู่แผงสำคัญไม่ทับกัน ขนาดปุ่มหลักอย่างน้อย 44px
- React DOM: resize แนวตั้ง/แนวนอน, pointer จอยและนิ้วที่สองโจมตีพร้อมกัน, pointercancel คืนจอย, เปิดเมนูหยุดเดินและล้างคำสั่งโจมตีค้าง
- Phaser HEADLESS: เปลี่ยนขนาดกล้องจริง แปลงพิกัดหน้าจอเป็นโลก แตะ NPC เปิดบทสนทนา เดินด้วยเวกเตอร์สัมผัส และหยุดขณะพักเกม
- เควส: เล่นครบ 12 เควสผ่านตัวลดสถานะจริง ส่งของหลายผู้รับ บันทึกระหว่างส่งของ เงื่อนไขวัตถุดิบ การสำรวจนับหลังรับงานเท่านั้น ห้ามรับรางวัลซ้ำ และคำตอบผิดไม่เสียเงิน
- UI: ลงทะเบียน สร้างตัวละคร ส่งเควสบทแรก เปิดสมุด 3 บท/12 เควส ตรวจปุ่มเควสบทใหม่ เซฟและโหลดบัญชี
- ชุดทดสอบอัตโนมัติ 25 ชุดผ่านทั้งหมด

## สิ่งที่ยังไม่ได้ยืนยัน

ภาพ CSS จริง การตัดบรรทัดภาษาไทย พื้นที่รอยบาก/แถบ Safari การตอบสนองบนฮาร์ดแวร์จริง ประสิทธิภาพเฟรมเรต เสียง และการเรียกเต็มจอบนอุปกรณ์ ยังต้องทดลองใน Safari iOS และ Chrome Android

สภาพแวดล้อม managed Linux ไม่มีเครื่องมือ `cua_repl.js` ที่ Sites รองรับ จึงไม่ได้เปิด preview/browser หรือใช้เครื่องมือควบคุมเบราว์เซอร์อื่นแทน ตาม Sites skill: “If cua_repl.js is unavailable, skip browser QA: do not start a preview server, install a browser, or improvise another browser-control path.”

เครื่องมือ remote desktop รายงาน enabled แต่สถานะ unknown; ไม่มี browser-control tool ให้เรียกใช้ใน session นี้
