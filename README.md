# Little Trade · ตลาดป่าพิกเซล

เกมผจญภัย Pixel RPG ภาษาไทย สำหรับเรียนรู้สินค้า บริการ การแลกเปลี่ยน อุปสงค์ และอุปทาน ระดับ ป.5

## GitHub และ Vercel

ทำตาม [คู่มือนำขึ้น Vercel ภาษาไทย](DEPLOY-VERCEL-TH.md) ได้เลย ใช้ Vite, Node.js 22.x, build `npm run build`, output `dist` มี `vercel.json` พร้อมแล้ว ส่งออกไฟล์สำหรับย้ายโฮสต์ด้วย `python scripts/package_source.py --github`

## เริ่มพัฒนา

ใช้ Node.js 22 ขึ้นไป:

```sh
npm install
npm run dev
npm test
npm run build
```

- React 19 จัดการหน้าจอ ตัวละคร กระเป๋า เควส การค้า และเซฟ
- Phaser 3 จัดการโลก กล้อง การเดิน คอลลิชัน สัตว์ มอนสเตอร์ และจอยสัมผัส
- Supabase Auth + PostgreSQL รองรับบัญชีและเซฟออนไลน์แยกเจ้าของ มี RLS และตรวจ revision ป้องกันเซฟเก่าเขียนทับเซฟใหม่
- ภาพแผนที่และตัวละครเป็นงาน Pixel ที่สร้างสำหรับเกมนี้ ฟอนต์และเพลงบรรเลงรวมในชุดเว็บแล้ว

## บัญชีออนไลน์ Supabase (username + รหัสผ่าน)

หน้าเริ่มเกมเลือก **ออนไลน์ Supabase** เป็นค่าเริ่มต้น ลงทะเบียนด้วย username และรหัสผ่าน Supabase Auth เก็บและตรวจรหัสผ่าน ส่วน `public.player_profiles` เก็บ `id`, `username`, `created_at` มี RLS ให้ผู้เล่นอ่านได้เฉพาะของตนเอง รหัสบัญชีเป็น UUID ของ Auth ไม่ใช่ UUID สุ่มในเบราว์เซอร์

โปรเจกต์ที่ตั้งค่าไว้: `iojxyqpysdqjrpdknkmx` URL หลัก `https://iojxyqpysdqjrpdknkmx.supabase.co` ใน src/backend.js ใช้เฉพาะ publishable key สำหรับ frontend

ขั้นตอนติดตั้งโดยเจ้าของโปรเจกต์:

1. หากติดตั้งตารางเซฟแล้ว รัน `supabase/username-auth.sql` ใน SQL Editor หากยังไม่เคยติดตั้ง ให้รัน `supabase/schema.sql` ซึ่งรวมทั้งบัญชีและเซฟแล้ว
2. Authentication → Sign In / Providers → Email: เปิด Email provider และ **ปิด Confirm email** เปิด Allow new users to sign up ด้วย
3. เปิดเกมรุ่นใหม่ เลือก ออนไลน์ Supabase แล้วลงทะเบียน ตรวจชื่อใน Table Editor → `player_profiles`; รายการบัญชีอยู่ใน Authentication → Users
4. เซฟตัวละครในเครื่องยังทำงานตามเดิม เปิดเมนูรูปเมฆแล้วกดบันทึกออนไลน์เพื่อเชื่อมตัวละคร หรือโหลดเซฟออนไลน์ เมื่อต่อสำเร็จระบบซิงก์ต่ออัตโนมัติขณะหยุดเดิน/เปิดเมนู

เนื่องจากไม่ใช้อีเมลจริง เกมแปลง username ที่ normalize NFKC/ตัวพิมพ์เล็กเป็น SHA-256 แล้วใช้ alias `HASH@players.littletrade.invalid` ภายใน Auth เท่านั้น Trigger ตรวจว่า alias ตรงกับ username ก่อนสร้างโปรไฟล์ ชื่อผู้เล่นจริงอยู่ใน player_profiles และ user_metadata.username ไม่มีการเก็บรหัสผ่านในโปรไฟล์ และไม่มีการกู้รหัสผ่านด้วยอีเมลสำหรับบัญชีแบบนี้

ระบบตรวจ Confirm email และ RPC readiness ก่อนสมัคร หากยังไม่ตั้งค่า จะหยุดที่หน้าสมัครพร้อมแจ้งขั้นตอน ไม่เปลี่ยนไปสร้างบัญชีในเครื่องเงียบ ๆ

บัญชีจากรุ่นเก่ายังเปิดด้วยโหมด **บัญชีในเครื่อง** ได้ บัญชีเก่าจะไม่ถูกอัปโหลดอัตโนมัติ: เลือกโหมดนี้เพื่อเข้าสู่ระบบเดิมและดาวน์โหลดเซฟ จากนั้นลงทะเบียนบัญชีออนไลน์แล้วนำเข้า JSON ในเมนูจัดการเซฟ รหัสผ่านเดิมไม่ถูกคัดลอกไป Supabase

เปลี่ยนโปรเจกต์ได้ด้วยค่าตอน build:

```env
VITE_SUPABASE_URL=https://YOUR_PROJECT.supabase.co
VITE_SUPABASE_PUBLISHABLE_KEY=YOUR_PUBLIC_PUBLISHABLE_KEY
```

## วิธีตรวจฐานข้อมูล

`player_profiles` คือชื่อบัญชี, `auth.users` คือข้อมูลยืนยันตัวตนของ Supabase และ `trade_game_saves` คือความก้าวหน้าตัวละคร การลงทะเบียนสร้างโปรไฟล์ทันที ส่วนตารางเซฟมีแถวหลังเริ่มตัวละครแล้วบันทึกออนไลน์

คีย์สาธารณะสร้างตารางหรือเปลี่ยน Confirm email ไม่ได้ เจ้าของโปรเจกต์ต้องทำสองขั้นตอนนี้ใน Dashboard การถูกปฏิเสธเมื่อ anon อ่านตารางเซฟเป็นพฤติกรรมตาม RLS ให้เข้าสู่ระบบแทนการเปิดสิทธิ์ตารางต่อสาธารณะ

## วิธีเล่น

- หน้าแรกมีปุ่ม Start และตั้งค่า กด Start เพื่อเข้าสู่ระบบหรือลงทะเบียนด้วย username และรหัสผ่าน จากนั้นตั้งชื่อ เลือกเพศ สีผิว ทรงผม และเครื่องแต่งกายก่อนเข้าหมู่บ้าน
- เดินด้วย WASD/ลูกศร คลิกหรือแตะจุดหมาย (มีการหาเส้นทางหลบสิ่งกีดขวาง) หรือจอยสัมผัส
- E / ปุ่มโต้ตอบ: คุย เก็บของ เปิดโต๊ะผลิต และพักที่บ้าน
- Space / ปุ่มดาบ: โจมตีมอนสเตอร์ พลังหมดกลับหมู่บ้านโดยไม่เสียของหรือเงิน
- คุยกับทิวเพื่อเริ่มเควสหลัก 12 เควสใน 3 บท และรับเควสย่อยอีก 9 เควส
- ผลิตขนมปัง ยา และเครื่องมือที่โต๊ะผลิตหน้าร้านช่างไม้
- พักที่บ้านเพื่อเติมพลังหรือขึ้นวันใหม่ ทรัพยากร ความต้องการชาวบ้าน และตลาดจะเริ่มรอบใหม่
- คำถามสรุปตอบผิดลองใหม่ได้ ไม่มีการหักคะแนนหรือเงิน

NPC ทั้ง 12 คนมีเพศ วัย อาชีพ รูปลักษณ์ และความต้องการแตกต่างกัน การแลกของมีจำนวนจำกัดในแต่ละวัน และตลาดมีงบรับซื้อวันละ 200 เหรียญ ราคาจากแบบจำลองอุปสงค์/อุปทานมีช่วงจำกัดเพื่อการเรียนรู้ ราคาซื้อรวมค่าบริการร้านค้า 2 เหรียญ

## เซฟและอัปเดตเนื้อหา

หนึ่งตัวละครมี UUID แยกจากชื่อ เก็บรูปลักษณ์ สินค้า เงิน หัวใจ ตำแหน่ง วัน เควส ประวัติการค้า สมุดความรู้ และความคืบหน้าแยกจากข้อมูลแผนที่/สูตร/เควส เพิ่มเนื้อหาใน `src/content.js` และ `src/world-data.json` โดยรักษา id เดิม และเพิ่ม migration ใน `src/engine.js` เมื่อต้องเปลี่ยนรูปแบบเซฟ เซฟจากอนาคตจะถูกปฏิเสธแทนการล้างข้อมูล

เซฟ localStorage แยกไม่เกิน 20 ตัวละคร ดาวน์โหลด/นำเข้า JSON ได้ เมื่อล้างข้อมูลเบราว์เซอร์เซฟในเครื่องอาจหาย ควรใช้บัญชีออนไลน์หรือดาวน์โหลดสำรอง

## ต้นฉบับภาพและการทดสอบ

`python scripts/create_world.py` ใช้ Pillow สร้างแผนที่และข้อมูลสิ่งกีดขวางใหม่ ไม่ต้องติดตั้ง Python เพื่อรันเว็บ

ผ่านการทดสอบอัตโนมัติ 30 ชุด รวมการรันฉาก Phaser แบบ HEADLESS จริงเพื่อทดสอบการเดิน หยุดขณะเปิดเมนู เก็บของ และต่อสู้ และทดสอบ React DOM ตั้งแต่สร้างตัวละครจนจบบทและแยกเซฟชื่อซ้ำ การทดสอบครอบคลุมการทำเควสจนจบบท คำถามผิดไม่เสียเงิน การรับรางวัลซ้ำ จำนวนความต้องการ NPC ต้นทุนการผลิต ราคาตามเหตุการณ์ การกู้ตัวละครหลังพลังหมด เซฟ และเส้นทางไปยัง NPC/ทรัพยากร/มอนสเตอร์ทุกจุด

ยังไม่ได้ตรวจภาพจริงและการสัมผัสผ่านเบราว์เซอร์ในสภาพแวดล้อมพัฒนา เนื่องจากไม่มีเครื่องมือ browser QA ที่ Sites รองรับให้ใช้ การทดสอบ Supabase แบบลงชื่อเข้าใช้ต้องทำหลังรัน schema โดยเจ้าของโปรเจกต์

## หน้าเริ่มเกมและการเล่นเต็มพื้นที่จอ

ลำดับหน้าจอ: เมนู Start/ตั้งค่า → ออนไลน์ Supabase หรือบัญชีในเครื่อง → สร้างตัวละคร → แผนที่เต็มจอ ผู้เล่นที่มีเซฟในเครื่องของบัญชีเดียวกันจะเล่นต่อได้ทันที และโหลดเซฟออนไลน์จากเมนูรูปเมฆได้

- Username ใช้อักษรไทย อังกฤษ ตัวเลข และ _ จำนวน 3–24 ตัว ปรับ NFKC และไม่แยกตัวพิมพ์อังกฤษ
- รหัสผ่าน 6–128 ตัว บัญชีออนไลน์ใช้ Supabase Auth; บัญชีในเครื่องเดิมใช้ PBKDF2-SHA256 210,000 รอบพร้อม salt สุ่ม
- เซฟ localStorage แยกตามรหัสบัญชี ไม่มีการรวมความก้าวหน้าของคนละบัญชีโดยอาศัยชื่อที่เหมือนกัน
- เลือกเพศ สีผิว ทรงผม สีผม ชุด และเครื่องประดับได้อย่างอิสระ
- ปุ่มตั้งค่าปรับเพลง ระดับเสียง จอย และการสั่นกล้อง ใช้เต็มพื้นที่เว็บได้ ส่วนการซ่อนแถบเบราว์เซอร์ขึ้นกับอุปกรณ์

## การคุยกับ NPC และภาพเวอร์ชัน Colorful

แก้พิกัดจุดโต้ตอบของ NPC ให้เป็นหน่วยเดียวกับตำแหน่งภาพในโลก Phaser และแยกชื่อที่แสดงผลออกจาก Text object ของ Phaser เพื่อให้ปุ่มคุยแสดงข้อความได้ถูกต้อง แตะตัวหรือป้ายชื่อเพื่อเดินเข้าไปเปิดบทสนทนาอัตโนมัติ หรือเดินเข้าใกล้แล้วกด E / ปุ่มโต้ตอบ จุดหมายเควสเปลี่ยนตามภารกิจหลักที่สำเร็จ

ทิว เชน และไมค์มีแผงส่งเควสด้านบนของบทสนทนา แสดงเงื่อนไขที่ครบ/ยังขาดและปุ่มส่งเควสโดยตรง ป้องกันรับรางวัลซ้ำตามกติกาเดิม

ข้อความในสมุดเควส เมนู บทสนทนา และหน้าสร้างตัวละครเป็นสีดำ ปรับฉากเป็น Colorful เพิ่มเงาต้นไม้ อาคาร และตัวละคร แสงแดดอุ่น เงาสะท้อนสีเย็น และสีหลังคา/น้ำให้สดใส โดยรักษาพิกัดสิ่งกีดขวางและเซฟเดิมไว้

เพิ่มการทดสอบฉากจริงแบบ HEADLESS ให้แตะหัว NPC จากระยะไกลแล้วเดินไปคุย ส่งเควสแรกและเควสบริการ และกด E คุยกับชาวบ้านทั้ง 12 คน ตรวจว่าข้อความปุ่มคุยเป็น string และพิกัดตรงกับภาพ พร้อมทดสอบปุ่มส่งเควสและจุดหมายถัดไปใน React DOM

## มอนสเตอร์เกิดใหม่ สัตว์ป่าสำหรับล่า และอาหาร

เพิ่มจุดเกิดคงที่ 9 จุด: มอนสเตอร์ 5 รัง และสัตว์ป่าสำหรับล่า 4 รัง (ไก่ป่า 2, หมูป่า 2) ใช้ actor เดิมซ้ำเพื่อจำกัดจำนวน ไม่เพิ่มมอนสเตอร์อย่างไม่สิ้นสุด เมื่อถูกกำจัด แต่ละจุดนับถอยหลัง 60–90 วินาทีเฉพาะขณะเล่น มีวงเตือนอย่างน้อย 3 วินาทีและรอจนผู้เล่นห่างจากรังเกิน 180 หน่วยโลกก่อนเกิด หยุดนับเมื่อเปิดเมนู ซ่อนแท็บ หรือออกเกม และเก็บเวลาที่เหลือไว้ในเซฟ การพักขึ้นวันใหม่ไม่รีเซ็ตเวลาของรัง

- ไก่ป่า: วิ่งหนีเมื่อเข้าใกล้ พลัง 2 ได้เนื้อดิบ 1
- หมูป่า: พลัง 3 เตือนทิศทาง 750 ms ก่อนพุ่ง หากโดนจะเสีย 2 หัวใจ ได้เนื้อดิบ 2
- สัตว์ตกแต่งเดิม เช่น กระต่าย กวาง นก และผีเสื้อยังเป็นสัตว์บรรยากาศ
- เนื้อดิบ + ไม้ 1 → เนื้อย่าง 1 ฟื้น 2 หัวใจ
- เนื้อดิบ 2 + สมุนไพร 1 + น้ำ 1 → สตูว์ 1 ฟื้น 4 หัวใจ
- ทำอาหารที่โต๊ะผลิต กินจากกระเป๋า ขายหรือซื้อในตลาดได้ อาหารไม่ถูกใช้เมื่อพลังเต็ม
- เค้กรับเนื้อย่าง 2 ชิ้น แลก 36 เหรียญ วันละหนึ่งรอบ และกลับมารับงานได้หลังขึ้นวันใหม่
- เพิ่มเควสย่อยนักหาเสบียง นักทำอาหาร และส่งเสบียง พร้อมปุ่มนำทาง

คงเควสหลักเดิมไว้ การล่าสัตว์ไม่นับเป็นการกำจัดมอนสเตอร์ในเควสเปิดเส้นทาง แต่ละชีวิตของรังมี cycle token ป้องกันการรับของซ้ำ และโบนัสเปิดเส้นทางได้รับครั้งเดียว เซฟรุ่นเดิมถูกเติมข้อมูลรังและสินค้าใหม่โดยไม่ลบเงิน รูปลักษณ์ หรือเควสเดิม

การทดสอบใหม่ครอบคลุมการกลับมาเกิดจริงใน Phaser การพักตัวนับเมื่อเปิดเมนู/ซ่อนแท็บ การรอจุดเกิดปลอดภัย ไก่ป่าให้เนื้อและไม่เพิ่มจำนวนมอนสเตอร์ที่กำจัด หมูป่าเตือนก่อนพุ่ง การทำ/กินอาหาร ส่งเสบียงรายวัน ราคาตามอุปทาน และนำเข้าเซฟที่ยังมีเวลานับถอยหลัง


## แคมเปญ 3 บทและหน้าจอมือถือ

เควสหลัก 12 เควส: บทแรก 5 เควสเดิม, บทผู้ผลิตและนักบริการ 4 เควส, บทเครือข่ายการค้า 3 เควส เพิ่มการเตรียมเสบียง ผลิตเครื่องมือ ส่งยาวาว้า→เชน วางแผนร้านค้า ส่งสินค้าเค้ก→จีโน่→เมญ่า สำรวจโกเลม/หมูป่าหลังรับภารกิจ และเตรียมตลาดใหญ่พร้อมคำถามสรุป 3 ข้อ สมุดแสดงเงื่อนไขและนำทางตามผู้รับของแต่ละขั้น

เซฟเดิมที่จบ 5 เควสจะเป็น 5/12 และเล่นต่อเควสเสบียงได้ทันที เงิน รูปลักษณ์ และรางวัลเดิมยังอยู่ พัสดุระหว่างส่งและจุดเริ่มนับการสำรวจบันทึกข้ามการโหลดได้ ห้ามรับรางวัลซ้ำและไม่มีการหักคะแนนเมื่อตอบผิด

จอมือถือใช้ HUD แบบย่อและปุ่มหลักอย่างน้อย 44px รองรับแนวตั้ง/แนวนอนและ visual viewport จอยจับ pointer เดียวเพื่อให้ใช้อีกนิ้วโจมตีได้ หยุดเมื่อ pointer ถูกยกเลิก เปิดเมนู หรือออกจากหน้าต่าง

ผลทดสอบแบบจำลองอยู่ที่ `public/setup/mobile-test-report.md` ครอบคลุม geometry 6 ขนาดจอ, React DOM touch events และการแปลงพิกัดกล้อง/แตะ NPC ใน Phaser HEADLESS 7 ขนาดรวมแท็บเล็ต **ยังไม่ได้ทดสอบผ่านเบราว์เซอร์บนโทรศัพท์จริงหรือยืนยันภาพ CSS จริง** จึงไม่รับรองผลแทน Safari/Chrome บนอุปกรณ์


## รูปแบบตัวละครจิบิ

ตัวผู้เล่นและ NPC ใช้สไปรต์พิกเซล 48×64 แบบหัวโต มีขอบสีน้ำตาล ผมไล่เฉด แก้มอมชมพู เสื้อครีมกับชุดสีที่เลือก เข็มขัด กระเป๋าหรือลายผ้ากันเปื้อน ปรับแต่งจากข้อมูล look เดิมได้ทันทีโดยไม่ต้องย้ายเซฟ ท่าเดิน 3 เฟรมต่อทิศรองรับ 4 ทิศ ภาพในหน้าสร้างตัวละคร บทสนทนา HUD และรายการเซฟใช้ตัววาดเดียวกัน

ดูภาพตัวอย่างที่ `public/art/character-preview.png` แก้รายละเอียดตัวละครใน `src/pixel.js` ตัวแปร PERSON_WIDTH/PERSON_HEIGHT กำหนดขนาดภาพ; PERSON_SCALE กำหนดขนาดในโลก เมื่อเปลี่ยนขนาดอีกครั้งให้ปรับ body offset ส่วนเท้าใน src/world.js ให้ตรงกันด้วย


## ตัวละครจิบิน่ารักและสัตว์หมู่บ้าน

ปรับสัดส่วนหัวกลมโตและตัวเล็กกว่าเดิม เพิ่มหมวกฟาง หมวกใบไม้ โบว์ริบบิ้น และแว่นนักประดิษฐ์ เลือกในหน้าสร้างตัวละครหรือแต่งตัวภายหลังได้ สีผมเพิ่มชมพู ลาเวนเดอร์ และเขียวอมจีโน่ เครื่องประดับบันทึกใน look.accessory เซฟเก่าที่ไม่มีฟิลด์นี้แสดงเป็นไม่ใส่หมวก

เพิ่มสัตว์เป็นมิตร 6 ตัวใน src/village-pets.js: คอร์กี้โมจิ แมวพุดดิ้ง กระต่ายปุยฝ้าย แม่เป็ดและลูกเป็ดสองตัว แตะตัวสัตว์เพื่อเดินไปลูบ หรือเข้าใกล้แล้วกด E/ปุ่มโต้ตอบ สัตว์แสดงหัวใจและขยับตอบรับ โดยไม่รับรางวัลซ้ำหรือเปลี่ยนจำนวนการล่าสัตว์ สัตว์กลุ่มนี้แยกจากสัตว์ป่าและไม่ถูกโจมตี

โมจิและพุดดิ้งอยู่ใกล้ลานเริ่มต้น ปุยฝ้ายอยู่ใกล้บ้าน และครอบครัวเป็ดอยู่ทางใต้ของลำธาร ปรับตำแหน่งได้ใน VILLAGE_PETS; สไปรต์ 2 เฟรมวาดจาก drawPet และใช้ซ้ำจาก texture cache


## รายชื่อตัวละครหมู่บ้าน

ทิว, ไมค์, เค้ก, จีโน่, เมญ่า, วาว้า, เชน, ไอเดีย, วิสา, โฟกัส, จูมง และลิตา รวม 12 คน รักษา id เดิมของ NPC แปดคนแรกเพื่อให้เควสและเซฟเดิมทำงานต่อได้ เพิ่มสี่คนพร้อมอาชีพและรายการแลกเปลี่ยนของตนเอง ชื่อในคำบอกทาง/เควสใช้ชื่อใหม่ ส่วนบันทึกบทเรียนเก่าที่อยู่ในไฟล์เซฟเป็นประวัติเดิม

## การตรวจระบบบัญชีรุ่นนี้

ทดสอบฟอร์มสมัครออนไลน์ด้วย SDK boundary จำลอง ตั้งแต่ Confirm email เปิดอยู่/SQL ยังไม่ติดตั้งจนลงทะเบียน เข้าสู่เกม บันทึกในเครื่อง ออกจากบัญชี และล็อกอินกลับ ตรวจว่าไม่สร้างบัญชี local เมื่อเลือกออนไลน์ ทดสอบ SQL จริงบน PostgreSQL 16 ที่แยกชั่วคราว: สร้างโปรไฟล์ผ่าน trigger, alias ภาษาไทย, RLS เจ้าของ/คนอื่น/anon, ปฏิเสธ alias ปลอม และรัน schema ซ้ำโดยข้อมูลไม่หาย

การตรวจแบบอ่านอย่างเดียวในโปรเจกต์จริงก่อนส่งรุ่นนี้พบว่า Confirm email ยังเปิด และยังไม่มี player_profiles จึงยังไม่ได้ทดสอบสมัครบัญชีจริงในโปรเจกต์ ต้องรัน SQL และปิด Confirm email โดยเจ้าของก่อน
